Frequently asked questions

Short answers to the things people actually ask.

Is HardMon free?

Yes. Free for personal and internal business use. Redistribution of the binary outside the official download page is not allowed.

Why is the archive password-protected?

The password github26 is public and not a security control. It exists so browser scanners and endpoint security don't quarantine the file mid-download, and so users receive the exact published binary. Verify SHA-256 after extracting.

Windows SmartScreen warns about HardMon.exe — is it safe?

SmartScreen warns on every unsigned binary from a new publisher. Verify the SHA-256 hash from SECURITY.md; if it matches, click "More info → Run anyway".

Does it send data anywhere?

No. Zero telemetry, zero analytics, zero phone-home. HardMon works fully offline.

Do I need admin rights?

No. Core monitoring works as a standard user. Elevation is only useful for certain temperature sensors on some motherboards.

Can I run it from a USB stick?

Yes. Single executable, portable design, no registry writes.

Where does it store settings?

Next to HardMon.exe in a HardMon.settings file. Delete the folder and everything is gone.
